# VectorKeith 公司资产 App

手机上实时查看公司链上资产的 PWA（可"添加到主屏幕"，像 App 一样使用）：公司钱包里的 SOL 和美元稳定币、股东分红、质押、资金流水与地址投毒提醒、推送通知，以及一条公司自建的 Solana 技术单节点区块链「VK 链」。

数据全部直接来自 Solana 主网，不依赖任何中心化数据库。后端只读链上数据；凡是需要动用资金的操作（质押、销毁、发放），服务器只组装未签名交易并先在链上模拟，签名永远在用户自己的钱包里完成。

## 功能

- **公司总资产**：一个或多个公司钱包的 SOL（含计入资产的质押）+ 官方 USDT / USDC（1 枚按 1 美元），人民币、美元、SOL 同时显示，余额毫秒级更新。冒牌稳定币（名字像 USDT、合约不对）不计入，并标黄提醒。
- **资金流水**：每一笔交易还原交易后的余额，分为转入、转出、买卖代币、稳定币转入转出、质押、网络费；识别**地址投毒**（开头结尾和自己钱包很像的骚扰转账）。
- **资产走势 / 时光机 / SOL 价格图**：按每笔交易还原历史余额，按当时价格折算；SOL K 线标出公司的进出。
- **股东与分红**：股东名册、持股比例、分红池（默认只按 SOL × 10%）、自动识别链上发给股东的分红；每位股东有自己的查看码，只看得到自己。
- **登录与权限**：公开 / 需要登录两种模式；管理员密钥、股东查看码、员工登录码、账号密码多种身份；令牌可随时吊销。
- **手机推送**：到账、转出、地址投毒、分红到账、目标达成、成就解锁（Web Push，自己实现的 RFC 8291 / 8292 加密，不依赖第三方推送服务）。
- **质押**：公司质押总览、推荐验证者、一键质押 / 解除 / 提取（钱包签名）；个人质押查询与收益计算。
- **内部质押**：员工充值到单独的质押钱包，按年化计息，自动对账、赎回申请、一键发放。
- **模拟盘**：用虚拟 SOL 体验 pump.fun 式的发币曲线和 AMM，带 K 线。
- **探索**：成就墙、"如果 SOL 价格变成…"模拟器、到账金币雨和语音播报、公司吉祥物和公司目标、办公室大屏模式（`#/screen`）、年度报告（`#/report`）。
- **VK 链**：Agave（Solana）+ Alpenglow 共识的单节点区块链，原生币 VK 付 gas。App 内置区块浏览器、本地私钥钱包（签名在手机上完成）、一键发行 Token-2022 资产（链上元数据）、水龙头、公开 RPC 代理；"公司资产凭证"cSOL / cUSDT / cUSDC 按主网真实余额自动增减、不可转让，用来公开核对公司储备。

## 技术栈

- 后端：Node.js 22+ / TypeScript（tsx 直接运行），原生 `http` + `ws`，零数据库（JSON 文件存储）
- 前端：React 19 + Vite，TradingView lightweight-charts，lucide 图标
- 链上：Solana JSON-RPC（HTTP + WebSocket 订阅），手写交易编码（无 @solana/web3.js 依赖），`@noble/curves` 做 ed25519

## 快速开始

```bash
npm ci
cp .env.example .env      # 至少填 TOKEN_MINT 和 ADMIN_KEY
npm run dev               # 后端 :8787 + 前端热更新 :5173
```

生产模式：

```bash
npm run build             # 构建前端到 dist/web
npm start                 # 后端同时托管前端（单端口 8787）
```

第一次打开后：

1. 「设置」→ 输入 `ADMIN_KEY` 进入管理 → 添加公司钱包（只需要钱包地址，**不需要也绝不要填私钥**）。
2. 模拟盘的初始账号（admin、vk1–vk12）的登录密码和初始交易密码都是 `changeme123`，**首次使用后立即修改**。
3. 需要"登录后才能用"时，在「设置 → 访问设置」切换成"需要登录"。

## 配置（.env）

| 变量 | 说明 |
|---|---|
| `TOKEN_MINT` | 必填，要跟踪的 pump.fun 代币地址 |
| `ADMIN_KEY` | 管理员密钥（≥ 6 位） |
| `PORT` | 服务端口，默认 8787 |
| `RPC_URL` / `RPC_WS_URL` | 私有 Solana RPC（强烈推荐，公共节点限速严格） |
| `DATA_DIR` | 数据目录，默认 `data` |
| `PUBLIC_ORIGIN` | App 对外网址（VK 链资产元数据里的图标链接） |
| `PUSH_SUBJECT` | 推送服务的联系方式（`mailto:` 或网址） |
| `VKCHAIN_RPC` | VK 链节点 RPC，默认 `http://127.0.0.1:8899` |

## 部署

`deploy/` 里有示例：

- `vectorkeith.service`：systemd 服务（专用低权限账户运行，只允许写 `data/`）
- `Caddyfile`：HTTPS 反向代理（证书自动签发）
- `setup-chain.sh`：安装 VK 链节点并生成创世区块（节点所有端口只对本机开放，对外只有经过 App 代理的 RPC；账本已存在时拒绝重新创世）
- `vkchain-backup.sh`：VK 链每日备份（创世文件 + 最新账户快照 + 密钥）

也可以用 Docker：

```bash
docker build -t vectorkeith-asset-app .
docker run -d -p 8787:8787 -v $(pwd)/data:/app/data --env-file .env vectorkeith-asset-app
```

## 安全

- `data/` 里有访问令牌签名密钥、推送密钥、VK 链金库私钥和全部业务数据，`.env` 里有管理员密钥：都已在 `.gitignore` 里，**不要提交**。
- 主网资金：服务器上没有任何主网钱包私钥；所有动用资金的交易都由用户在自己的钱包里签名。
- VK 链是单节点链，由运营方控制；VK 和链上资产没有市场价格，不能兑换。对外发行代币或以代币融资在很多地区受严格监管甚至被禁止，使用前请先咨询律师。
